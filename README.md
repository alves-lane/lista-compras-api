O projeto utiliza java maven, spring boot e spring web para criação da API REST, para gerar o esqueleto do projeto foi utilizado o site https://start.spring.io

A classe Produto é o modelo de dados.
A classe ProdutoService é a regra de negócios com a função teste.
A classe ProdutoController é referente a camada rest.
A classe ListaComprasApplication utiliza o framework bootstrap.
